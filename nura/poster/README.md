# Poster

`Nura-poster.pdf` — 1400 × 900, the site's own colours and typefaces.

Headline, one line on what is there, and a plum band saying the site is live with the
link in the submission description. No URL printed on it, deliberately: the link goes in
the description field where the contest expects it, and a URL on a poster is one more
thing that can go stale.

Rebuild after any edit to `poster.html`:

```
node poster/build.mjs
```
